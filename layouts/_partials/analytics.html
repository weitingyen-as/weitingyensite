{{- /* Cookieless GA4, via Consent Mode. VERIFIED IN A BROWSER, because the obvious approach silently fails: gtag('config', ..., {client_storage: 'none'}) is a Universal Analytics option that GA4 ignores -- the page still received _ga and _ga_ cookies. The mechanism GA4 actually honours is a consent default of analytics_storage: 'denied', pushed BEFORE the config call. GA4 then sends cookieless pings: page views are recorded, nothing is stored on the device, and no persistent identifier follows the visitor. The cost is that every page view looks like a new visitor, so "users" and "returning visitors" in the GA dashboard are not meaningful. Page views, referrers, pages per session and geography still are. The ad_* denials switch off advertising, remarketing and demographics. IP anonymisation is not set: GA4 does it unconditionally, and the old anonymize_ip parameter is ignored, so passing it would only mislead. Do Not Track is honoured, as in Hugo's own template: nothing runs at all. */ -}} {{- with site.Config.Services.GoogleAnalytics.ID -}} {{- end -}}
