These directories hold one-line redirect stubs, not site content.

weitingyen.com used to run WordPress. When the domain moved to this Hugo site,
every old WordPress URL started returning the 404 page -- and people still
arrive on them from bookmarks, citations and search results. Each stub sends
the visitor to the matching section of the new single-page site.

The paths were taken from the Internet Archive's record of the old site
(the CDX API), not guessed, so this covers what actually existed.

Generated once; edit or add by hand. Delete a directory to drop a redirect.
